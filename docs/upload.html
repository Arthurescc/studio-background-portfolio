QUICK UPLOAD

一次发布，后台自动完成剩余工作。

  1. 01
    创建批次标签

    使用 `batch-日期-编号`，例如 batch-2026-08-001。

  2. 02
    拖入 ZIP 压缩包

    每包建议500–1000张；支持一个批次上传多个 ZIP。

  3. 03
    发布 Release

    点击 Publish release，自动任务立即开始。

  4. 04
    等待自动整理

    系统解压、生成每张原图独立 URL、缩略图、图库目录及 Excel/CSV。
