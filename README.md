# Studio Background Library

一个面向设计师、电商从业者和内容创作者的公益摄影棚背景素材库。

本仓库采用“**GitHub Releases 保存原始压缩包和独立原图 + GitHub Pages 自动生成可视化图库**”的结构。素材发布后，每张图片都有独立下载 URL；原始 ZIP 同时保留，方便整批下载。

## 如何浏览和下载

- 在线图库：通过仓库首页右侧的 **Deployments** / **Pages** 链接进入。
- 整批下载：进入 [Releases](../../releases)，选择对应批次下载 ZIP。
- 每张预览卡片提供独立原图下载入口。
- URL 表格：在线图库提供自动更新的 Excel 和 CSV。

## 素材发布说明

素材通过 GitHub Releases 分批发布。GitHub Release 的单个附件必须小于 2 GiB；较大的素材批次可以拆成多个独立 ZIP 放在同一个 Release 中。

建议每个 ZIP 控制在 1.8–1.9 GB，避免触及单文件上限。ZIP 可包含多层文件夹，但不应包含密码保护文件、可执行文件或无关内容。

## 为什么不直接提交所有原图

普通 Git 仓库不适合长期存放大量二进制图片。Release 用于保存完整 ZIP 和独立原图；Git 分支仅保存网页、索引和轻量预览，以保持仓库易于浏览和维护。
